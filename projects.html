Before you start a project

  • Make sure you can program the board. Follow Getting Started once, including the C setup for Project 3.
  • Look up the pins you need in the pin map.
  • Start from the closest example in your language. Reusing a delay, LCD or 7-segment routine is fine and saves time.
  • Never let the program end: finish assembly with an infinite loop (SJMP $) and C with for (;;) in main().
