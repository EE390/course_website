Software

MIDE-51 ASM

Free IDE with the 8051 assembler used in the course (Windows). Also usable as the editor for C files.

opcube.com ↗

STC-ISP v6.91K

Programmer for STC microcontrollers. Portable — no installation needed, just run the .exe.

Download .exe (5 MB) Official ↗

SDCC C

Free, open-source C compiler for the 8051, used for the C projects. Install version 4.5 with “Add to PATH”.

sdcc.sourceforge.net ↗ build.bat

CH340 USB-serial driver

Needed if Windows doesn't create a COM port for the board.

wch-ic.com ↗

Board manual (Chinese)

Puzhong 51 MCU Development Guide — A2 board (普中 51 单片机开发攻略, 313 pages). The official manual for our board. It is in Chinese and its code is in C, but the hardware design sections and schematics apply directly. Use your browser's or phone's translate feature on the PDF if needed.
