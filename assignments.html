Assignments

There are two kinds of assignment. Homework is done individually. Practical Assignments are the mini projects on the board and are done in groups of 2 to 3 students. Due dates are on the Schedule.

Practical Assignments Groups of 2–3

Mini projects build something real on the development board, first in assembly and then in C. Each has a project page with the requirements, a starter template and grading. Practical Assignment 1 runs in two stages.

TitleLanguageYou learn
1 · Bird Sound SynthesizerASMTimers, interrupts, lookup tables, timing accuracy
2 · Bird Sound Synthesizer in CCEmbedded C with SDCC, interrupts and memory in C, comparing C with assembly

Before you start

  • Make sure you can program the board. Follow Getting Started once, including the C setup for Project 2.
  • Look up the pins you need in the pin map.
  • Start from the closest example in your language. Reusing a delay, LCD or 7-segment routine is fine and saves time.
  • Never let the program end: finish assembly with an infinite loop (SJMP $) and C with for (;;) in main().
