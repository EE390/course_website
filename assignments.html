Before a practical quiz

  • Make sure you can program the board — follow Getting Started once.
  • Look up the pins you need in the pin map.
  • Start from the closest code example — reusing a delay, LCD or 7-segment routine is fine and saves time.
  • End every program with an infinite loop (e.g. HERE: SJMP HERE) so the CPU doesn't run into empty memory.
